# Crunchify trial workspace

This is a local planning workspace and starter scaffold, not a completed trial project. Read [the complete re-plan](docs/CRUNCHIFY-MASTER-PLAN.md) and [requirements tracker](docs/REQUIREMENTS-TRACEABILITY.md), and view the current PNG concepts under `wireframes-v3/`, including the mobile-first and separate staff sign-in boards.

- `reference/` contains the client-provided Drive kit and email attachments. It is ignored by Git because the material is non-public.
- `web/` is the Next.js / TypeScript / Tailwind starter. See its README for local setup.
- `wireframes-v3/` contains the current Drive-based concept images. `concepts/homepage/` contains a separate local HTML/CSS visual prototype used for the corrected homepage boards; its links are not implemented application routes. Both and earlier concept folders are ignored by Git so client material is not accidentally committed. The concepts are also in the user-specified Drive folder.
- No production service, database, email provider, VPS, or Git remote is configured yet. Do not put credentials or real lead data in Git.
